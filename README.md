## 🚀 Cara Menjalankan Secara Lokal

Cukup buka file `index.html` langsung di browser Anda, atau gunakan static local server:

### Menggunakan Python:
```bash
python -m http.server 8080
```
Buka browser pada `http://localhost:8080`

### Menggunakan Node.js (npx serve):
```bash
npx serve .
```

## 🌐 Cara Deploy ke GitHub Pages

1. **Inisialisasi Git dan Push ke GitHub**:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit modern portfolio for GitHub Pages"
   git branch -M main
   git remote add origin https://github.com/naufalsho/Portofolio_githubpages.git
   git push -u origin main
   ```

2. **Aktifkan GitHub Pages**:
   - Masuk ke repositori Anda di GitHub: `https://github.com/naufalsho/Portofolio_githubpages`
   - Buka tab **Settings** > **Pages** (di sidebar kiri).
   - Pada bagian **Build and deployment**:
     - **Source**: Pilih `Deploy from a branch`.
     - **Branch**: Pilih `main` dan folder `/ (root)`.
     - Klik **Save**.
   - Tunggu 1–2 menit, portofolio Anda akan tayang di:
     **`https://naufalsho.github.io/Portofolio_githubpages/`**
